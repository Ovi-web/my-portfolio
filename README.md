# Developer Portfolio ⚡

A high-performance, modern, and fully responsive Developer Portfolio web application built to showcase software engineering expertise, technical projects, and academic background. Features a custom multi-theme design system and interactive components.

## 🔗 Live Link: [Live Demo Link Coming Soon]()

---

## 🚀 Technologies Used

- **React (TypeScript):** Component architecture, custom hooks, and strict type safety.
- **Tailwind CSS:** Responsive layouts, utility-first styling, and custom design tokens.
- **Framer Motion & Lucide Icons:** Fluid UI animations and clean iconography.
- **Web3Forms API:** Client-side contact form delivery directly to email without a custom backend.
- **LocalStorage API:** Client-side persistence for active theme state.

---

## ✨ 5 Key Features

1. **Tri-Theme Architecture (Dark, Neon Blue, Light)**  
   Interactive theme switcher supporting clean light mode, deep dark mode, and a futuristic neon-cyan palette with glowing borders. Persists preferences across reloads.

2. **Interactive Project Showcase & Dynamic Modals**  
   Detailed card views for featured applications (`BazarDor`, `FitLog`, `Dev Stack`) equipped with interactive modal popups revealing architectural challenges, tech stacks, and live links.

3. **Categorized Graphical Skills Grid**  
   Structured visualization of technical competencies categorized across Frontend, Backend & Systems (including Go), Databases, and Developer Tools.

4. **Functional Contact Workflow**  
   Direct contact interface powered by Web3Forms for immediate message delivery to email, featuring client-side validation, loading states, and toast notifications.

5. **Integrated Resume Access & Direct Socials**  
   One-click direct resume download link (`/resume.pdf`) alongside quick-navigation social badges (GitHub, LinkedIn, X).

## 💻 Getting Started Locally

To run this project locally, follow these steps:

### 1. Clone the Repository
```bash
git clone [https://github.com/Ovi-web/my-portfolio.git](https://github.com/Ovi-web/my-portfolio.git)
cd my-portfolio
2. Install Dependencies
Bash
npm install
3. Run the Development Server
Bash
npm run dev
4. Open in Browser
Open http://localhost:5173 (or http://localhost:3000) in your browser to view the application.
